# YW Concept 圖示描述與視覺參考

本文件整理使用者提供的圖示重點，方便對照官方定義。

## 1. H-Pattern 官方示意圖（兩張相同結構）

**重點特徵標註：**
- 左側長直大陰 K 形成「h」的第一筆垂直線
- 之後出現一小波段的橫向/輕微回調（less than 50% pullback）
- 轉彎處有明顯 top wick（上影線）顯示 selling pressure
- 最後向下穿底（跌破前低）完成形態
- 藍色 20EMA 向下傾斜作為背景
- 時間框架標註為 3min/5min

**市場意義：** 長直下跌後的弱勢反彈失敗，賣壓重新掌控。

## 2. 3 Pushes + Divergence 範例（Russell 2000 + ES 對照）

**上圖（Russell 1min）：**
- 清楚可見三次向上推高嘗試
- 最後一次推高失敗（Equal High 附近）
- 綠色箭頭標示 3 次嘗試新高失敗

**下圖（ES 1min）：**
- 同樣時間段也有 3 pushes 痕跡，但較不明顯
- 標題：「3 PUSHES AND DIVERGENCE AT THE HIGHS: MID-DAY BREAKOUT ATTEMPT DENIED」

**重點：** 指數間出現 divergence（Russell 更弱），強化反轉可信度。

## 3. 兩陽夾一陰 / 燭身結構範例

多張 K 線特寫顯示：
- 中間一根較深色實體
- 左右兩根相對較淺色實體
- 只關注 body，忽略影線（符合 YW「只關注燭身」的要求）
- 常出現在盤整尾段

## 4. RSI Divergence 範例（價格 LL + RSI HL）

- 價格圖：兩個黃色圓圈標示 Lower Low（LL）
- 下方 RSI：對應位置出現 Higher Low
- 形成經典看漲 divergence（或 SMT 類似概念）
- 之後價格確實向上反彈

## 5. 下跌通道 + 3 Pushes / Trendline 範例

- 藍色 20EMA 向下
- 綠色下降趨勢線連接低點
- 價格在通道內做多次反彈後再度破位
- 有些圖顯示最後一推收窄

## 6. 實際 NQ 5min 交易截圖（多張）

**共同特點：**
- 使用 Fibonacci Retracement（0.5、0.618、0.786 等）
- 紅色箭頭標示進場/壓力位置
- 藍色箭頭標示支撐或反向
- 有明確 TP / SL 標註（例如 +1860 USD、+2610 USD）
- 部分顯示「1L」倉位
- 價格在 20EMA 下方運行時偏空
- 有灰色方塊標示 consolidation / OTE 區域

**典型結構：** Big Downtrend + Trendline + 3 pushes → 0.5-0.618 OTE + consolidation → 突破 5min EMA 後進場。
