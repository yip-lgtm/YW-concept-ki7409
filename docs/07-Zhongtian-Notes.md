# 種田策略重點整理

> 注意：完整「种田.pdf」內容未直接提供，以下整理自 YW 頻道轉發訊息與群友實際運用分享。

## 核心思路（來自冒險島 c 哥授權轉發）

種田 = 低風險、穩定累積、以時間換取通關與出金的穩健打法。

## 實務執行框架（群友運用 YW Concept 的版本）

### 大方向過濾（1 小時）
- 20 EMA 作為價值參考
- 價格在 20EMA 下方 + 約 45 度傾斜 → 只考慮做空
- 反之只考慮做多（或觀望）

### 中期結構（5 分鐘）
- 確認 bearish / bullish structure
- 尋找 Sweep、Liquidity、未填補 FVG

### 精確進場（1 分鐘）
- 等待 Sweep + BOS
- 20 EMA respect
- 出現 H Pattern（或其他 YW 定義的觸發）

### 風險與目標
- 種田節奏目標通常為 $150 – $250 左右
- 強調高勝率、小而美的利潤，而非單筆暴擊
- 嚴格遵守 Prop Firm 的 MLL 與 Consistency Rule

## 與暴擊流的對比

| 項目       | 種田流                  | 暴擊流                      |
|------------|-------------------------|-----------------------------|
| 風險比例   | 較低（約 MLL 5-10%）   | 較高（可到 30%+）          |
| 目標       | 穩定小利、時間換通關   | 快速達成 Profit Target     |
| Setup 要求 | 高質量 + 多重確認      | 高質量但更積極出手         |
| 心態       | 耐心、紀律、生存優先   | 等待好 Setup + 實時管理    |

## 注意事項

- 種田不是「隨便進場」，仍然需要符合 YW Concept 的形態與結構
- 建議配合 PropStat 等工具追蹤 ROI 與勝率
- 完整 PDF 建議直接向頻道原始分享者索取，以獲得最完整的執行細節
