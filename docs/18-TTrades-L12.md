# 18. TTrades L12 — Candle 2 Closure

Candle 2 closure 是 Fractal Model 的反轉收盤，用來生成 swing 候選。無高時間框 POI、無配對周期 CISD，不當交易。

## 1. 兩種收盤

對照前一根 C1。

| 類型 | 空頭例子 | 含義 |
|------|----------|------|
| 延續收盤 | 掃過 C1 低，收在該低之下 | 趨勢未斷，預期續跌 |
| 反轉收盤（C2 closure） | 掃過 C1 極值後收回 C1 區間內 | 轉折候選 |

- 看漲 C2：掃過 C1 低點，收盤在該低點之上，且仍在 C1 範圍內。
- 看跌 C2：掃過 C1 高點，收盤在該高點之下，且仍在 C1 範圍內。

只掃不收回 = 延續，不是 C2。先掃流動性、再收回，是他們對 swing point 的核心定義。

## 2. 之後期待

- C2 成立後期待 C3 延續這次反轉。
- C3 強勢收破 C2 極值，再期待 C4 延續。
- 進入 C5、C6，講者當新價格階段，要收手。這條沒有明確界線，屬事後判斷，實盤不單獨當硬閘。

長影線加 EQ：C2 影線長時，C3 應尊重影線上半的 0.5。守不住，swing point 不易算成立。C2 本身淺影線、大實體拉開，代表擴張可能已在 C2 完成，對做 C3 不利。

## 3. 必須有 POI

見到掃入收回就做，勝率低。C2 必須落在高時間框關鍵位：前高、前低、或 FVG。

進階例外：沒掃到 POI，但已形成 protected swing，可用對向蠟燭當 POI。這不是默認開倉條件。

練習順序：日線先標所有轉折 → 刪不符合 C2 定義的 → 刪不在 POI 的 → 剩下的先定隔日偏向。

## 4. 低周期確認

日線 C2 之後，降到配對周期找 CISD。筆記配對：日線配小時、小時配 5 分鐘，逐層往下。

CISD：找出造就高點（或低點）的一連串蠟燭，等收盤跌破（或升破）該系列極值。價格不回到前高之內（可配 EQ），維持原方向。

例子（筆記）：微型比特幣期貨月線掃前高收回成 C2，日線同步 CISD，之後在 T-spot 順勢空。這是月線／日線 fractal，不是 5 分鐘單獨觸發。

## 5. 開倉名單（對齊 L12）

1. 高時間框 POI（前高／前低／FVG）
2. C2：掃 C1 極值並且收回區間內
3. 配對低周期 CISD
4. 才期待 C3；C2 收盤當下不按固定 ATR 開倉

無 POI 的 C2 只是候選生成器。真正分開輸贏的是 POI 同 CISD，不是形態本身。

## 6. 同現有 pipeline 的缺口

9/22 類訊號「H4 C2 + M15 CISD」只做了後兩步，缺日線偏向同 POI。5 分鐘主圖直接跑 C2，對不上 L12 的 fractal 配對。BTC 口數必須用風險金額除停損距離，禁止按名義 0.6 幣以上。
