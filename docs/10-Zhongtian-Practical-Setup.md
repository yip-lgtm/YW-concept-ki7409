## 實際 Setup 例子（群友運用）

完整過濾流程：

1. **1 小時圖** 定大方向  
   - 使用 20EMA 判斷價值  
   - 價格在 20EMA 下方，且呈現約 45 度傾斜 → **只做 Short**

2. **5 分鐘圖** 看 structure  
   - 是否 bearish  
   - 有沒有 sweep  
   - 有沒有 liquidity 或未補的 FVG

3. **1 分鐘圖** 等待精確觸發  
   - Sweep + BOS  
   - 20EMA respect  
   - 出現 H Pattern

4. **入場與目標**  
   - 目標約 **$150 – $250**（種田節奏）

此流程將 YW 的 H Pattern 與大方向過濾結合，適合穩定累積的種田打法。
