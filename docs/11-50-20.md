# YW Concept：50/20（20EMA / 50SMA 刮均線）

來源：YW Discord `#📖｜ywconcept百科全書` + 种田.pdf（冒險島群友 @M. 與相關分享）

## 核心定義

**50/20** 指使用 **20 EMA + 50 SMA** 作為趨勢跟隨工具的刮均線打法。

主要時間框架：
- 5min / 15min / 60min（標準趨勢跟隨）
- 強勢單邊時可下到 1min

## 標準進場節奏

1. **金叉確認**  
   5 分鐘圖上，20 EMA 上穿 50 SMA 形成黃金交叉，代表短期趨勢初步確立。

2. **耐心回踩**  
   不追高。等待價格回踩均線，腳步踩穩後再順勢進場。  
   回踩不破，才是真正的上車點。

3. **順勢上車**  
   回踩確認後直接做多（或反向做空）。

## 強勢單邊行情處理

- 切換至 **1 分鐘圖**
- 價格摸到 20 MA 即買進
- 回調至 50 MA 可少量加倉
- 均線被「拽下來」的時候，往往是較好的再進場機會

## 出場與保本心法

- 盈虧比達到 **1 RR 以上**，或碰到前期波段高/低點（Swing High/Low）→ 分批平倉
- 帳面一旦有利潤，立刻把止損推到進場點附近（**保本**）
- 大不了白玩一趟，絕不讓利潤大幅回吐

## 與種田流的結合

| 項目 | 規則 |
|------|------|
| 單筆止損 | $200–$300 |
| 每日停利 | 賺到 $200–$300 立即收工 |
| 每日停損 | 累計虧損 $400–$600 強制停手 |
| 帳戶 | 標準 $50,000，最大回撤 $2,000（4%） |
| 多帳戶 | 3–4 個一組複製，風險隔離 |
