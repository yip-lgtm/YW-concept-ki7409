# YW Concept：輔助技巧

## 1. 看不懂 NQ 走勢時

打開 **ES 圖表** 在旁邊一起看，增加自己信心。

當 NQ 的結構或動能看起來模糊時，同步對照 ES（S&P 500 期貨）可以幫助判斷整體市場方向是否一致，減少單看一個指數的主觀偏誤。

## 2. 慢牛快熊

YW 於 **2026/7/15** 提出的觀察。

市場上漲往往呈現較緩慢、階梯式的推進（慢牛）；下跌則常常來得又急又猛（快熊）。此觀察有助於調整持倉耐心與止損節奏——做多時可給更多時間，做空時則需更敏捷地管理風險。
