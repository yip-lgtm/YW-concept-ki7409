## 2. 兩種風險打法

### 種田流（保守）
- 單筆風險約 MLL 的 5–10%
- 以時間換取穩定通關
- 高生存率、培養紀律

### 暴擊流（激進）
- 單筆風險可達 MLL 的 30% 以上（高品質 Setup）
- 目標快速達成 Profit Target + Consistency Rule
- 強調「等好 Setup」+ 實時倉位管理
- YW 有專門精華講解暴擊流與實時管理
