# YW Concept: 3 Pushes（官方定義）

來源：YW Discord 頻道 `#📖｜ywconcept百科全書`（2026/4/13）

**時間框架**：5min / 15min chart

## 特點（YW 原文）

1. **三推**
2. **最後一推收窄**
3. **With Equal High/Low to break**  
   （有等高原點/等低原點可被突破）

## 補充觀察（來自圖表與實戰）

- 常出現在高點（或低點）的連續三次嘗試，最後一次力度減弱（收窄）。
- 可與指數間 divergence 結合（例如 Russell 更明顯做出 3 pushes 失敗，而 ES 相對強）。
- 典型用法：Big Downtrend + Trendline + 3 pushes → 0.5–0.618 OTE + consolidation → 突破 5min EMA。

## 與 H Pattern 的聯動

三推常作為更大背景，H Pattern 則作為更精細的進場觸發（尤其在 3min/5min）。
