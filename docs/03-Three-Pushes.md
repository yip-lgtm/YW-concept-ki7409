# 三推結構（Three Pushes）深入解析

三推結構是價格行為中判斷動能衰竭的核心工具，Al Brooks 體系將其視為多種反轉形態的共同底層行為。YW 將其與 H Pattern 結合應用於 NQ 日內。

## 核心定義

價格在同一方向連續出現 **三次推動**，每次嘗試創新極值但動能逐漸減弱。

- 第一推：動能較強
- 第二推：仍創新高/低，但力度開始減弱
- 第三推：最關鍵，常過沖通道線後失敗，形成衰竭訊號

本質：趨勢方努力三次後力竭 → 被套者出場 + 逆勢者進場。

## 主要類型

### 反轉型三推
- 上升趨勢末端三次上推（Rising Wedge）→ 容易轉空
- 下降趨勢末端三次下推（Falling Wedge）→ 容易轉多
- 特徵：趨勢線與通道線收斂、第三推動能明顯不足

### 延續型三推（三推旗形 / 楔形回調）
- 趨勢中的三次逆勢回調，完成後繼續原趨勢
- 適合順勢重新進場或加倉

## 進場細節

1. **第三推後的反轉信號棒**（最推薦）：出現明確反轉 K 線後，突破信號棒高/低點進場
2. **二次進場（Second Entry）**：第一個信號失敗後的第二次機會，勝率通常更高
3. **通道線過沖失敗**：第三推過沖後迅速收回時進場
4. **突破回測**：形態完成後回測邊界再拒絕

延續型：三推回調完成後，等順勢突破或反轉信號重新加入原趨勢。

## 止損與目標

- **止損**：第三推極值之外
- **第一目標**：形態起點（第一推起點）
- **第二目標**：以整個三推高度進行測量移動（Measured Move）
- 可部分獲利 + 移動止損

## 與 H Pattern 的結合

三推常提供 H Pattern 形成的背景。例如在三推向上的第三推附近出現 H Pattern，做空勝率與 R:R 更佳。與 Always In Short 共振時優先級更高。

## 常見陷阱

- 數推起點的主觀性 → 優先交易最明顯、動能遞減清晰的結構
- 失敗三推本身可成為更強延續信號
- 過早在第三推完成前搶跑
- 忽略更大時間框架與 Always In 背景
