# YW Concept 實戰例子整理

## 例子 1：教科書級別 H-Pattern + 3 Pushes Short（2026/5/21）

**結構：**
- Big Downtrend
- Trendline
- 3 pushes
- → 進入 0.5 – 0.618 OTE 區域 + consolidation
- 突破 5min EMA 後進場

**目標：**
- First TP：last bottom wick
- Second TP：-0.272（約 29260）

結果：TP1 + TP2 都打到。

## 例子 2：種田式完整流程（群友分享，2026/6/10）

**步驟：**
1. **1 小時圖** 決定大方向  
   - 用 20 EMA 判斷價值  
   - 價格在 20EMA 下方，且呈現約 45 度傾斜 → 只做 Short

2. **5 分鐘圖** 看 structure  
   - 是否 bearish  
   - 有沒有 sweep  
   - 有沒有 liquidity 或未補的 FVG

3. **1 分鐘圖** 等待精確觸發  
   - Sweep + BOS  
   - 20 EMA respect  
   - 出現 H Pattern

4. **入場與目標**  
   - 入場後目標 $150 – $250（種田節奏）

## 例子 3：RSI Divergence（2026/5/5 19:00 HKT NQ）

- 價格做出 Lower Low
- RSI 做出 Higher Low
- 形成 Divergence
- 之後出現反彈機會

## 例子 4：實際 5min NQ 截圖中的共同模式

從多張實盤圖可見：
- 下跌趨勢中，價格多次測試 0.5 / 0.618 回撤後再破位
- 紅色箭頭常標在壓力區或進場點
- 藍色箭頭標在支撐或可能反彈點
- 倉位管理清楚標示 TP / SL 與浮動盈虧
- 當價格在 20EMA 下方且 EMA 向下傾斜時，空單優先

## 例子 5：指數對照技巧

當 NQ 走勢看不懂時，旁邊同步打開 ES 圖表。  
若 Russell 出現更明顯的 3 pushes 失敗，而 ES 相對強，則 divergence 訊號更有參考價值。
