# Oliver Kell — Cycle of Price Action Setups

來源：Oliver Kell, *Victory in Stock Trading*（2020 U.S. Investing Champion，+941%）。本文件為**研究摘要與期貨合流筆記**，非原文複製。

定位：中期趨勢跟隨 + 波段。價、量、均線、多時間框、形態。

---

## 工具（Kell）

| 類型 | 設定 |
|------|------|
| 均線 | **10 EMA**（所有時間框）、**20 EMA**（所有時間框）、**50 SMA**（日線）、**200 SMA**（日線） |
| 時間框 | 5m / 15m / 1H / Daily / Weekly / Monthly |
| 核心 | 價格為主、成交量作線索、均線騎趨勢 |

## Cycle of Price Action（價格循環）

**見頂 → 下跌 → 見底：**

`Exhaustion Extension → Wedge Drop → EMA Crossback → Base n' Break → Reversal Extension`

**見底 → 上升 → 見頂：**

`Reversal Extension → Wedge Pop → EMA Crossback → Base n' Break → Exhaustion Extension`

階段可以跳過，唔係機械必跟。用途：唔追高、站對邊、用低時間框入場、高時間框跟趨勢。

---

## Setup 1 — Reversal Extension（反轉延伸／見底）

**含義：** 恐慌延伸，遠離 10 EMA（中間有「空氣」），在 HTF 支撐反轉。

**條件：**
1. HTF 有明確支撐（日線 20EMA／50／200、前低等）
2. LTF 價格遠離 10 EMA
3. 出現反轉 K（最好大量 capitulation）

**執行：**
- 入場：反轉 K 確認後做多
- SL：反轉區低點下
- TP1：交易時間框的 **20 EMA**
- 部分平倉後推保本；剩餘用感覺／結構離場

**加倉用法：** 上升趨勢回踩日線 20EMA 時，用 **5min Reversal Extension** 精細入場（日線可能是 Base n' Break）。

**空頭相反。**

---

## Setup 2 — Wedge Pop / Wedge Drop

### Wedge Pop（轉多確認）
反轉延伸之後，第一次重新站上均線。

1. 價格收窄、偏低走
2. 相對大盤偏強（RS）更佳
3. 10／20 EMA 收窄（動能弱）
4. **價格重新奪回收窄的 10／20 EMA → 做多**
5. SL：近期盤整低點下
6. 用 EMA 作移動止損

可當「先前 Reversal Extension 有效」的確認。

### Wedge Drop（轉空確認）
耗盡延伸之後，第一次跌穿均線。邏輯對稱。

---

## Setup 3 — EMA Crossback（第一次回踩均線）

Wedge Pop 之後，**第一次**回踩 10／20 EMA。

1. 已站回 10／20 EMA
2. 第一次拉回均線
3. 在 10／20 EMA 做多
4. SL：均線下
5. 用 10／20 EMA 移動止損

下跌趨勢：第一次反彈到均線做空。

---

## Setup 4 — Base n' Break（盤整突破）

較長的沿 10／20 EMA 築底／盤整（長過 1–3 日回踩）。

1. 沿均線築底
2. 可先沿均線建倉，突破再加
3. SL：失守均線
4. 沿均線持有；遠離 10 EMA 的急升可減倉；最終失守 EMA 離場

**EMA Pullback Entry（較短）：** 1–2 日回踩均線，用來加倉或推止損。趨勢愈延伸，回踩勝率愈低。

---

## Setup 5 — Exhaustion Extension（耗盡延伸／見頂）

遠離 10 EMA 的吹頂／亢奮。

- 第二次遠離 10 EMA：常見減倉／止盈位
- 第三次延伸：中期趨勢後期，風險高
- 之後常接 Wedge Drop 確認轉勢

## 傳統形態（CAN SLIM 類，作選股／大結構）

| 形態 | 要點 |
|------|------|
| Cup + Handle | 杯右沿收緊 handle 後突破 |
| Double-Bottom | 雙底 + 低位 2B shakeout |
| Flat / Large Base | 數週至月線大底，突破可開新趨勢 |
| Bull Flag / Pennant | 短延續；破下降高點或收窄三角 |

Kell 會把這些大底，用上面 Cycle 的 Wedge Pop / Crossback / Base n' Break 分段執行。

---

## 選股濾鏡（股票；期貨可忽略基本面）

- 高增長：銷售／盈利增速佳、新主題、相對強度
- 流動性：通常日成交 ≥ 100 萬股、股價偏高（他避免 < $10）
- 指數回調時找「跌得少／更高低點」的 RS 股

## 同 YW / 种田 / TTFM 合流（MNQ 等）

| Kell | 本倉庫 |
|------|--------|
| 10／20 EMA 全時間框 | 种田 20EMA；50/20 策略的 20EMA |
| 50 SMA 日線 | 50/20 的 50SMA；Stair 的 50EMA 方向 |
| EMA Crossback / Pullback | **50/20 回踩入場** |
| Reversal Extension @ HTF 支撐 | CRT 掃 CRT-Low + MSS；TTFM C2 |
| Wedge Pop | C3／CISD 確認轉勢 |
| Base n' Break | 盤整尾突破；兩陽夾一陰類環境 |
| Exhaustion + Wedge Drop | 慢牛快熊；只做空／收工 |
| 高 TF 趨勢 + 低 TF 入場 | 1H 定方向 → 5m／1m 執行 |

**种田風控疊加：** 單筆約 $100、RR 1:1.5 或 TP1=20EMA、日停利 $200–$300、失守 EMA 離場。

### MNQ 5min 實用對照

1. **1H／日線** 20EMA 方向（只順勢）
2. 等 **EMA Crossback** 或短 **Pullback** 到 10／20
3. 合流 H Pattern／Stair／TTFM C2–C3 先入
4. 第一次延伸持有；**第二次遠離 10EMA 減倉**
5. Wedge Drop（失守 10／20）當趨勢結束
