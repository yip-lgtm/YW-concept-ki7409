# YW Concept：Stair Pattern（H Pattern 變體）

來源：YW Concept 整理（H Pattern 之變體）

**時間框架**：5min / 15min / 1hr

## 特點（官方定義）

1. **第 1 枝 candle：大陰燭**  
   - 大實體陰線  
   - 上影線很小或沒有  
   - 下影線可有；收盤位於整支陰燭 **50% 以下位置**（收在下半部，顯示空方主導）

2. **中段：數枝嘗試上升、但不斷受沽壓的 candle**  
   - 價格試圖反彈 / 回升  
   - 多次出現 **上影線**（賣壓拒絕高點）  
   - 形成階梯式、重心逐步下移或橫盤偏弱的結構（「楼梯 / stair」）

3. **最後確認**  
   - 最後一枝 candle **燭身收低於 20 EMA**  
   - 作為空方延續 / 破位確認訊號

## 結構示意

```
  ┌────┐
  │████│  ← 大陰燭（上影小/無，收在下半）
  │████│
  └──┬─┘
     │
    ┌┴┐     上影（沽壓）
    │░│
    └─┘
     │  ┌─┐  上影
     │  │░│
        └─┘
         │ ┌──┐
         │ │░░│  ← 燭身收於 20EMA 下方（確認）
           └──┘
     ─────────  20 EMA
```

視覺上：左側一根強勢大陰，右側數根較小 K 線「爬樓梯」式反彈失敗，最終收在 20EMA 之下。

## 與 H Pattern 的關係

| 項目 | H Pattern | Stair Pattern |
|------|-----------|---------------|
| 核心 | 長直 K 形成 h 的第一筆劃 → 轉彎有上影 → <50% pullback → 穿底 | 大陰啟動 → 多根上影沽壓階梯 → 收破 20EMA |
| 時間框 | 3min / 5min | 5min / 15min / 1hr |
| 確認 | 穿底 | **燭身收低於 20EMA** |
| 性質 | H Pattern 變體，同樣偏空方延續 / 破位邏輯 |

Stair 更強調「反彈失敗的階梯」與 **20EMA 收盤確認**，適合稍大時間框觀察結構。

## 進場邏輯（實務建議）

1. 先確認第 1 根符合大陰 + 收在下半部  
2. 觀察後續 2～N 根是否反覆出現上影、無法有效站穩  
3. 等待 **收盤低於 20EMA** 的那一根作為觸發  
4. 可結合：  
   - 更高時間框空方偏向（如 1H 在 20EMA 下方）  
   - 種田風控（單筆 $200–$300、日停利 $200–$300）  
   - 與 H Pattern、3 Pushes 同一套空方結構工具箱

## 注意事項

- 僅在有明確「大陰啟動 + 階梯沽壓」時使用，避免盤整雜訊中的假上影  
- 20EMA 確認以 **收盤** 為準，不只是影線刺穿  
- 大時間框（15min / 1hr）結構較乾淨，5min 需更嚴格過濾  
- 目前為概念定義整理，尚未做獨立大樣本回測
