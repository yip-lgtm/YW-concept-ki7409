# YW Concept：兩陽夾一陰

來源：YW Discord `#📖｜ywconcept百科全書`

**時間框架**：15min chart

## 特點（YW 原文）

1. **盤整的尾段出現**
2. **只關注燭身（candle body）**

## 形態說明

兩陽夾一陰是盤整末期常見的價格行為結構。重點不在影線，而在三根 K 線的實體關係：中間一根陰線實體被前後兩根陽線實體「夾住」。

出現在盤整尾段時，常暗示方向即將選擇，可作為突破或反轉的輔助確認訊號。

---

## 統計勝率深入分析

目前公開數據中，**沒有針對 NQ 15 分鐘、嚴格符合 YW 定義的大規模獨立回測**。以下整理最接近的統計結果。

### 1. 中文市場「兩陽夾一陰 / 多方炮」數據（A 股）

根據 Wind 與券商研究（2020–2024）：

| 條件 | 大致勝率 / 上漲機率 | 說明 |
|------|---------------------|------|
| 單純形態出現後 5 個交易日 | 約 **62.3%** | 基礎參考值 |
| 第三根陽線成交量 ≥ 中間陰線 1.5 倍 | 提升至約 **72%** | 量價配合是關鍵過濾 |
| 同時出現 MACD 0 軸上方金叉 | 可到約 **78%** | 動能共振 |
| 出現在大幅下跌後的底部區域 | 可高達 **80–90%**（反轉訊號） | 位置極重要 |
| 出現在上漲中途（突破均線後） | 約 **80%**（延續訊號） | 較佳 |
| 出現在大幅上漲後的高位 | 約 **70% 機率是誘多陷阱** | 必須避開 |

這些數字主要來自日線，對 NQ 15 分鐘只能作為方向性參考。

### 2. 西方類似形態量化結果

- **Stick Sandwich**（最接近的英文對應）：確認率約 37%，確認後達到 2:1 的機率約 42%，整體偏弱。
- **Three White Soldiers**：常被引用約 70%，但樣本稀少且訊號偏晚。
- **Bullish Engulfing / 類似三 K 線看漲結構**（有確認時）：約 55–65%；無確認時常掉到 47% 附近。
- **通用結論**：單一 candlestick 形態在沒有額外過濾時，勝率多落在 50% 上下。加上「位置 + 成交量 + 趨勢背景」後，才有機會拉到 60%+。

### 3. 日內（15 分鐘）現實

低時間框架噪音明顯較大：

- 5–15 分鐘圖原始 candlestick 形態勝率，常見落在 **44–55%** 區間。
- 日線或更高時間框架的同一形態，勝率通常較高。
- 期貨（NQ）受流動性、隔夜跳空、Macro 消息影響，單純形態可靠性會再被稀釋。

YW 特別強調「盤整的尾段」+「只關注燭身」，這兩個條件本身就是強力過濾器。

### 4. 在 YW Concept + 種田流中的合理預期

| 使用方式 | 預期勝率區間（粗估） | 說明 |
|----------|----------------------|------|
| 單純 15min 兩陽夾一陰 | 50–58% | 噪音大，容易假突破 |
| + 盤整尾段 + 只看 body | 55–65% | YW 原始定義的核心過濾 |
| + 1H 20EMA 方向一致 | 60–70% | 大方向過濾 |
| + 成交量配合 + structure/sweep | 65%+ | 高品質 Setup，適合種田 |

種田流目標是每筆 $150–$250、嚴格止損，因此即使勝率只有 55–60%，只要平均盈虧比維持在 1:1 以上，長期依然可以累積。

### 5. 關鍵結論

1. 沒有公開的 NQ 15min 精確勝率數字，任何「成功率極高」的說法都需要打折。
2. 位置（盤整尾段）與只看燭身，是 YW 版本最有價值的兩點。
3. 建議把此形態當成 **confluence 之一**，而不是獨立進場訊號。優先順序：1H 方向 → 5min structure → 15min 兩陽夾一陰（或 H Pattern）→ 1min 精確觸發。
4. 若要自己驗證，建議用 TradingView 或 NinjaTrader 對 NQ 15min 做標記回測，並嚴格加入「盤整尾段」與「body only」條件，樣本至少數百次以上才有參考價值。
