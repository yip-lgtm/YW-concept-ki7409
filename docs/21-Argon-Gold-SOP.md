# 21 - Argon 黃金極短線 SOP（15M 箱體 + M5 確認）

來源：Argon 高（截圖 2026-10-19）

## 核心前提

- 大勢明確（例：1H 多頭 HH + HL，空頭反之）
- 小勢回調進入「價值區」
- **不要盲目左側接刀**（黃金極容易一根針直接穿倉）
- 必須等待 **M5 或 M15** 收出以下標準裸K確認模型之一才進場（以多頭「順大勢買入」為例，空頭反之）

## 確認模型

### 模型 A：流動性掃蕩反轉 (Liquidity Sweep + Pin Bar / 吞沒) — 黃金短線首選

**結構特徵：**

價格回調至價值區或 M15 前一個次級低點時：

1. 先用一根下影線刺穿該低點（打掉提早進場多頭的止損單，完成流動性收集）
2. 隨後在同一根或下一根K線迅速拉回
3. 收出長下影線拒絕K線（**Pin Bar**，下影線長度大於K線總長度的三分之二）或強勢看漲吞沒（**Bullish Engulfing**，陽線實體完全包覆前一根陰線實體）

**進場與止損：**

- K線收盤確認後立即市價進場（或掛突破該K線高點進場）
- 止損設在掃損下影線最低點下方預留微幅價差緩衝

### 模型 B：小週期結構轉換（M5 雙底 + 結構破壞 MSB）— 最穩健

**結構特徵：**

價格回調至支撐區 / 價值區後：

1. M5 的下跌小趨勢（連續 Lower High + Lower Low）停止創出新低
2. 形成「小雙底」結構（兩個相近低點，第二個低點不破第一個，或僅微幅掃損後迅速拉回）
3. 隨後價格突破前一個較低高點（前 LH），完成市場結構破壞（**MSB / Break of Structure**）
4. 確認小週期由空轉多，趨勢轉換成立

**進場與止損：**

- MSB 確認後（M5 收盤突破前 LH）立即市價進場，或等待回踩前 LH 區域確認後進場
- 止損設在小雙底最低點下方預留微幅價差緩衝
- 若止損距離 > $5.0，依 SOP 放棄

> 此模型較模型 A 更穩健，因為要求明確的結構轉換（MSB），不僅靠單根拒絕K。

> 截圖未完整顯示第三種模型，以上兩種為主。

## 實戰 SOP（極短線）

**流程：** 15分鐘建箱體 → 5分鐘實體突破判定 → 止損距離檢查 → 1R保本與1.5R止盈

### 場景分類

| 場景 | 說明 | 操作 |
|------|------|------|
| **A：標準做多突破** | 15M 箱體建立後，M5 實體突破箱體高點 | 進場，SL 箱體低點下方 |
| **B：影線假突破** | 只影線突破，實體未破 | **過濾，不進** |
| **C：止損 > $5** | 止損距離過寬 | **放棄** |
| **D：箱體滾動做空** | 箱體內震盪反向 | 可考慮空單 |

### 進場規則（場景 A）

1. 1H 趨勢確認多頭（HH + HL）
2. 15M 建立清晰箱體（高點 / 低點）
3. M5 收盤實體突破箱體高點（非單純影線）
4. 止損放在箱體低點下方（或掃損低點下）
5. 若止損距離 > $5.0，放棄
6. 進場後：1R 移止損至保本，1.5R 止盈

## 風險管理

| 項目 | 規則 |
|------|------|
| 單筆風險 | $50 |
| 止損上限 | ≤ $5.0（過寬放棄） |
| 保本 | 1R 後移 SL 到進場價 |
| 止盈 | 1.5R |
| 標的 | 現貨黃金 XAUUSD |

## 注意事項

- 這是極短線操作，重點在確認K線收盤，避免盲接。
- 模型 A（流動性掃蕩 + 拒絕）與模型 B（雙底 + MSB）可並用；B 較穩健、A 較敏感。
- 止損過寬直接放棄，保持資金效率。
- 可與之前的 50/20 EMA、Stair Pattern 等結合使用。

## 實作狀態（2026-10-20）

- 偵測器：`automation/src/yw_indicators_argon.py`
- 執行標的：**GC=F**（COMEX 黃金主力期貨，每金衡盎司報價，與現貨同尺度）。
  本系統無 XAUUSD 現貨行情源（yfinance 無 XAUUSD=X / XAU=X），GC=F 為最接近的代理。
  刻意不在 MGC=F 上重複執行：兩者為同一黃金底層，同一 setup 會被開兩次。
- 觸發窗口：掃描最近 6 支 5 分鐘 K 線（30 分鐘）。15 分鐘的掃描週期只會抽到每第三支
  5 分鐘 K 線，僅看最後一支會漏掉三分之二觸發機會。
- **預期信號頻率極低：約每 5 小時一次機會**。近 200 支 GC=F 5 分鐘 K 線中只有 3 次符合條件，
  主要被「1H 偏向不明顯」擋下（224 次），其次是「突破箱體但無確認模型」（36 次）。
  這是 SOP「極短線 + 大勢明確 + 嚴格確認」的正常結果，不是故障。
  **若要提高頻率而放寬 1H 偏向門檻，等於偏離本 SOP 明文寫出的前提。**
