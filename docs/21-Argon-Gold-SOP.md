# 21 - Argon 黃金極短線 SOP（15M 箱體 + M5 確認）

來源：Argon 高（截圖 2026-10-19）

## 核心前提

- 大勢明確（例：1H 多頭 HH + HL，空頭反之）
- 小勢回調進入「價值區」
- **不要盲目左側接刀**（黃金極容易一根針直接穿倉）
- 必須等待 **M5 或 M15** 收出以下標準裸K確認模型之一才進場（以多頭「順大勢買入」為例，空頭反之）

## 確認模型

### 模型 A：流動性掃蕩反轉 (Liquidity Sweep + Pin Bar / 吞沒) — 黃金短線首選

**結構特徵：**

價格回調至價值區或 M15 前一個次級低點時：

1. 先用一根下影線刺穿該低點（打掉提早進場多頭的止損單，完成流動性收集）
2. 隨後在同一根或下一根K線迅速拉回
3. 收出長下影線拒絕K線（**Pin Bar**，下影線長度大於K線總長度的三分之二）或強勢看漲吞沒（**Bullish Engulfing**，陽線實體完全包覆前一根陰線實體）

**進場與止損：**

- K線收盤確認後立即市價進場（或掛突破該K線高點進場）
- 止損設在掃損下影線最低點下方預留微幅價差緩衝

### 模型 B：小週期結構轉換（M5 雙底 + 結構破壞 MSB）— 最穩健

（截圖截斷）在支撐區後，M5 的下跌小趨勢（LH + HL）停止創出新低，形成「小雙底」，然後結構破壞（MSB）確認轉換後進場。

> 截圖未完整顯示第三種模型，以上兩種為主。

## 實戰 SOP（極短線）

**流程：** 15分鐘建箱體 → 5分鐘實體突破判定 → 止損距離檢查 → 1R保本與1.5R止盈

### 場景分類

| 場景 | 說明 | 操作 |
|------|------|------|
| **A：標準做多突破** | 15M 箱體建立後，M5 實體突破箱體高點 | 進場，SL 箱體低點下方 |
| **B：影線假突破** | 只影線突破，實體未破 | **過濾，不進** |
| **C：止損 > $5** | 止損距離過寬 | **放棄** |
| **D：箱體滾動做空** | 箱體內震盪反向 | 可考慮空單 |

### 進場規則（場景 A）

1. 1H 趨勢確認多頭（HH + HL）
2. 15M 建立清晰箱體（高點 / 低點）
3. M5 收盤實體突破箱體高點（非單純影線）
4. 止損放在箱體低點下方（或掃損低點下）
5. 若止損距離 > $5.0，放棄
6. 進場後：1R 移止損至保本，1.5R 止盈

## 風險管理

| 項目 | 規則 |
|------|------|
| 單筆風險 | $50 |
| 止損上限 | ≤ $5.0（過寬放棄） |
| 保本 | 1R 後移 SL 到進場價 |
| 止盈 | 1.5R |
| 標的 | 現貨黃金 XAUUSD |

## 注意事項

- 這是極短線操作，重點在確認K線收盤，避免盲接。
- 結合流動性掃蕩（模型 A）可提升勝率。
- 止損過寬直接放棄，保持資金效率。
- 可與之前的 50/20 EMA、Stair Pattern 等結合使用。
